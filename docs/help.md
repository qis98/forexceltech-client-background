# FOREXCELTECH 客户背景管理系统帮助文档

## 1. 产品当前功能概览

FOREXCELTECH 客户背景管理系统当前是一个 Windows 本地桌面应用，用于帮助销售人员沉淀客户资料、关键联系人和拜访沟通记录。

当前版本已经可用的功能：

- 工作台：查看客户、联系人、拜访记录数量，以及最近客户。
- 客户管理：新增、编辑、查看、软删除客户。
- 客户筛选：按状态、行业、区域筛选客户。
- 全局搜索：在客户页搜索客户；在联系人页搜索联系人、客户、职位、部门、关系或偏好；在拜访记录页搜索主题、客户、参与人、摘要或下一步动作。
- 客户详情：查看客户基础信息、主要产品信息、客户背景、备注、关键联系人、拜访/沟通记录。
- 联系人管理：联系人页展示所有客户的联系人，客户详情中可新增、编辑、软删除联系人。
- 拜访记录管理：拜访记录页展示所有客户的沟通时间线，客户详情中可新增、编辑、软删除拜访/沟通记录。
- 智能录入：支持粘贴文字稿、预关联客户/联系人、调用 Ollama 本地模型或本地规则生成可编辑客户/联系人/拜访记录草稿，一段文字稿可生成多个联系人草稿，并人工确认写入数据库；缺失字段显示“未知，待人为补充”。
- 客户地图：离线展示客户分布，支持省份分布、城市级点位、省内客户列表、状态/行业筛选和客户详情跳转。
- 设置：通过顶部齿轮或原生菜单“设置 > 打开设置”进入，支持配置智能录入、日历配色、数据位置和数据管理。
- 数据备份：在设置页把 SQLite 数据库复制到 D 盘备份目录。
- 数据恢复：在设置页从备份数据库恢复当前数据，恢复前会自动备份当前数据库。
- CSV 导出：在设置页导出客户、联系人、拜访记录 CSV 文件。
- 客户档案导出：在客户页按筛选条件批量导出 Markdown、PDF 或 Word 档案，可选择是否包含联系人和拜访记录。
- 界面规范：左侧菜单、顶部操作按钮、工作台数据卡和联系人/拜访记录列表已统一为蓝色线性图标和商务按钮样式。
- 大数据浏览：客户、联系人和拜访记录列表支持分页，默认每页 50 条，可切换 20、50 或 100 条。
- 本地数据存储：默认数据库固定保存到 `D:\FOREXCELTECHClientManager\data.db`。
- 打包运行：已支持 Windows 安装包和免安装版 exe。

当前版本尚未实现的功能：

- 项目机会管理。
- 待办提醒。
- Excel 导入。
- 附件管理。
- 实时录音和实时转写。
- 本地离线语音转文字。
- 多用户账号、权限和云同步。
- 项目机会、待办和附件的全文搜索。

## 2. 数据保存位置

应用默认使用本地 SQLite 数据库，路径为：

```text
D:\FOREXCELTECHClientManager\data.db
```

应用会自动创建以下目录：

```text
D:\FOREXCELTECHClientManager\attachments
D:\FOREXCELTECHClientManager\ai-drafts
D:\FOREXCELTECHClientManager\backups
D:\FOREXCELTECHClientManager\exports
D:\FOREXCELTECHClientManager\logs
D:\FOREXCELTECHClientManager\temp
```

Ollama 本地模型默认保存位置：

```text
D:\FOREXCELTECHClientManager\ollama-models
```

Ollama 用户目录保存位置：

```text
D:\FOREXCELTECHClientManager\ollama-home
```

`C:\Users\songmu\.ollama` 只是指向该 D 盘目录的联接。

本地模型配置文件保存位置：

```text
D:\FOREXCELTECHClientManager\config.json
```

当前数据库路径可在“设置”页查看。正常情况下应显示：

```text
D:\FOREXCELTECHClientManager\data.db
```

## 3. 启动软件

开发阶段可用命令启动：

```powershell
pwsh.exe -NoProfile -Command "$env:PATH = 'D:\DevTools\NodeJS;D:\DevTools\SQLite;' + $env:PATH; & 'D:\DevTools\NodeJS\npm.cmd' start"
```

打包后可直接运行：

```text
D:\FOREXCELTECHClientManager\release\win-unpacked\FOREXCELTECHClientManager.exe
```

也可以使用安装包：

```text
D:\FOREXCELTECHClientManager\release\FOREXCELTECHClientManager-Setup-0.1.0-x64.exe
```

或免安装版：

```text
D:\FOREXCELTECHClientManager\release\FOREXCELTECHClientManager-Portable-0.1.0-x64.exe
```

## 4. 工作台

打开软件后默认进入工作台。

工作台显示：

- 客户数量。
- 联系人数量。
- 拜访记录数量。
- 最近客户列表。

界面说明：

- 在应用最小窗口宽度下，工作台三张统计卡保持横向排列，最近客户区域保持首屏可见。
- 工作台数据卡使用统一蓝色图标和轻量卡片样式，减少颜色干扰。

新增客户统一使用顶部右上角“新增客户”按钮；也可以点击最近客户进入客户详情。

## 5. 新增客户

操作路径：

1. 点击顶部右上角“新增客户”。
2. 填写客户名称。
3. 根据需要填写简称、行业、状态、重要等级、负责人、电话、网站、地址、标签、主要产品信息、客户背景和备注。
4. 区域不需要手动填写：选择或识别出省份后，系统会自动按省份归入华东、华南、华北、华中、西南、西北、东北或港澳台。
5. 城市必须先选择省份后再选择；城市列表只展示当前省份对应城市。
6. 点击“保存”。

说明：

- 客户名称为必填。
- 状态默认为“潜在”。
- 行业字段支持下拉已有行业，也可自行输入；内置常用项包含半导体设备、半导体、电子制造、自动化设备、精密制造、智能装备、新能源、汽车电子、存储、光模块。
- 重要等级建议使用 1-5。
- 标签使用逗号分隔。
- 保存成功后会自动进入客户页，并弹出该客户详情。

## 6. 编辑客户

操作路径：

1. 进入“客户”页面。
2. 点击客户卡片打开客户详情弹框。
3. 点击详情弹框右上角“编辑客户”。
4. 修改信息后点击“保存”。

客户页当前采用“列表页 + 详情弹框”结构：

- 客户列表页展示客户缩略重点信息，包括客户名称、行业、区域、状态、联系人数量、拜访记录数量和最近沟通时间。
- 客户列表默认分页展示，底部可切换每页 20、50 或 100 条，并支持上一页、下一页、首页和末页。
- 点击客户卡片后弹出客户详情弹框，不会把详情追加到页面底部。
- 客户页不再保留“选择客户”的大面积空白详情区，主页面只展示客户列表和筛选。
- 客户详情弹框中可编辑客户、新增联系人、新增拜访、删除客户；操作按钮已按主次层级统一，删除保持红色描边。
- 关闭弹框后仍停留在客户列表，便于继续浏览其他客户。

客户详情会展示：

- 客户状态。
- 最近沟通时间。
- 下一步动作。
- 基础信息。
- 客户背景。
- 备注。
- 关键联系人。客户详情中的关键联系人只展示已经填写的有效信息，不再固定展示空字段。
- 拜访/沟通记录。

## 7. 查找和筛选客户

顶部搜索框支持搜索：

- 客户名称。
- 客户简称。
- 行业。
- 区域。
- 主要产品信息。

客户页筛选支持：

- 状态：全部、潜在、活跃、停用。
- 行业：来自已有客户数据。
- 区域：来自已有客户数据。

界面说明：

- 在应用最小窗口宽度下，客户列表保持卡片化展示；点击客户后使用详情弹框查看完整信息，避免详情被挤到页面底部。
- 客户详情弹框右上角操作按钮保持紧凑排列，避免编辑、新增和删除按钮换行错乱。
- 新增/编辑客户、联系人、拜访记录时，表单内容区独立滚动，底部“保存/取消”操作栏固定可见。

如果没有匹配客户，列表会显示空状态。

## 8. 新增联系人

联系人页会显示所有客户的联系人，默认按最近更新时间从新到旧排序。

联系人列表默认分页展示，底部可切换每页 20、50 或 100 条，并支持上一页、下一页、首页和末页。

联系人页支持顶部搜索框，搜索范围包括：

- 联系人姓名。
- 户籍信息。
- 所属客户。
- 部门和职位。
- 电话、邮箱、微信。
- 关系状态。
- 沟通偏好。
- 个人兴趣、下次可提及话题和备注。

联系人列表采用统一商务卡片样式，重点展示联系人姓名、所属客户、行业/区域、影响力、关系状态、部门职位、沟通偏好和下次可提及话题。

点击联系人列表中的联系人卡片会打开“联系人详情”弹框，可查看完整联系方式、关系、偏好、话题、经历和备注。弹框中可继续点击“查看客户详情”跳转到所属客户，或点击“编辑联系人”修改资料。

联系人新增和编辑当前仍从客户详情中维护。

操作路径：

1. 进入客户详情。
2. 点击“新增联系人”。
3. 填写姓名。
4. 根据需要填写性别、户籍信息、部门、职位、电话、邮箱、微信、学历、专业背景、工作年限、影响力、关系状态、沟通偏好、决策角色、个人兴趣、下次可提及话题、过往任职经历和备注。
5. 点击“保存”。

说明：

- 姓名为必填。
- 性别使用“男/女”分段选项，不需要手动输入。
- 影响力建议使用 1-5。
- 联系人会自动关联当前客户。

## 9. 编辑和删除联系人

在客户详情的“关键联系人”区域：

- 点击“编辑”可修改联系人。
- 点击“删除”会先弹出确认，确认后该联系人默认不再显示。

删除采用软删除策略，数据仍保留在数据库中。

## 10. 新增拜访记录

拜访记录页会显示所有客户的拜访/沟通记录，默认按发生时间从新到旧排序。

拜访记录列表默认分页展示，底部可切换每页 20、50 或 100 条，并支持上一页、下一页、首页和末页。

拜访记录页支持顶部搜索框，搜索范围包括：

- 拜访主题。
- 所属客户。
- 参与联系人。
- 地点。
- 摘要和详细内容。
- 客户态度。
- 下一步动作。
- 记录人。

点击拜访记录列表中的记录卡片会打开“拜访记录详情”弹框，可查看完整摘要、详细内容、参与人、客户态度和下一步动作。弹框中可继续点击“查看客户详情”跳转到所属客户，或点击“编辑拜访记录”修改记录。

界面说明：

- 拜访记录列表与联系人列表使用统一卡片密度和按钮风格。
- 拜访记录左侧优先展示发生日期和时间；列表中日期使用短格式，例如 `26/6/29`，完整时间可在详情弹框中查看。
- 右侧展示主题、所属客户、沟通类型、地点、参与人、摘要和下一步动作，便于快速回看沟通历史。

拜访记录新增和编辑当前仍从客户详情中维护。

操作路径：

1. 进入客户详情。
2. 点击“新增拜访”。
3. 选择沟通类型。
4. 填写主题和发生时间。
5. 根据需要填写地点、参与联系人、摘要、详细内容、客户态度/倾向、下一步动作和记录人。
6. 点击“保存”。

说明：

- 主题和发生时间为必填。
- 新增拜访时发生时间默认使用当前时间。
- 沟通类型支持现场拜访、电话、微信、邮件、同事转述。
- 可选择多个参与联系人。

## 11. 编辑和删除拜访记录

在客户详情的“拜访/沟通记录”区域：

- 点击“编辑”可修改拜访记录。
- 点击“删除”会先弹出确认，确认后该拜访记录默认不再显示。

删除采用软删除策略，数据仍保留在数据库中。

## 12. 智能录入

智能录入页用于把文字稿转换为客户、联系人和拜访记录草稿。

当前能力：

- 粘贴拜访、电话或会议文字稿。
- 在“设置”中启用 Ollama 本地模型后，优先使用本地模型结构化抽取。
- 选择“仅本地规则”或 Ollama 不可用时，使用本地规则生成客户草稿、联系人草稿和拜访记录草稿。
- 草稿字段可编辑。
- 一段文字稿中出现多位关键人时，会生成多张联系人草稿。
- 字段无法识别时显示“未知，待人为补充”。
- 必填字段缺失时显示待补充提示。
- 尝试匹配已有客户。
- 如果发现疑似已有客户，会显示“客户匹配确认”，必须人工选择“使用已有客户”或“按草稿新建客户”。
- 支持在生成草稿前预关联已有客户。
- 支持在生成草稿前预关联已有联系人；选择联系人后会自动反推其所属客户。
- 预关联客户和联系人通过搜索选择弹窗完成，结果列表分页展示，避免客户/联系人很多时下拉框过长。
- 预关联客户或联系人优先于 AI/规则推测，用于避免重复创建客户和联系人。
- 预关联客户或联系人优先级高于候选客户确认；这是录音或文字稿客户归属不清时的推荐做法。
- 客户草稿、联系人草稿和拜访记录草稿可分别确认写入。
- 智能录入客户草稿支持主要产品信息字段；联系人草稿支持户籍信息字段。
- 页面底部提供“全部确认写入”，会按客户、所有联系人、拜访记录的顺序写入。
- 联系人和拜访记录必须关联已匹配或已写入的客户，不能孤立入库。
- 拜访记录会自动关联本次已确认写入的多个联系人。
- 点击“生成草稿”后会显示进度条，生成期间按钮自动禁用，完成或失败后恢复。

界面说明：

- 智能录入页在小窗口下保持左右两栏，文字稿和草稿区各自滚动。
- “生成草稿”和“清空”按钮固定在文字稿面板底部，不需要下滑到页面底部。
- 结果区默认隐藏模型来源、草稿文件路径等技术信息，主界面只保留客户匹配和待确认草稿。
- 待确认草稿区是任务列表，只展示摘要、状态和操作按钮，不直接渲染完整字段。
- 点击草稿卡片或“编辑”会打开草稿编辑弹窗，完整字段在弹窗中修改。
- 草稿编辑弹窗底部固定“保存草稿”和“保存并写入”操作，长字段在弹窗内滚动。
- 客户匹配确认区改为紧凑纵向排版，避免小窗口中横向撑开。

操作路径：

1. 点击左侧“智能录入”。
2. 如果已知本次文字属于哪个客户，点击“预关联客户”，在弹窗中搜索并选择客户。
3. 如果已知本次拜访关联某位联系人，点击“预关联联系人”，在弹窗中搜索并选择联系人；系统会自动关联该联系人的所属客户。
4. 在“文字稿”区域粘贴沟通内容。
5. 点击“生成草稿”。
6. 在“待确认草稿”区域检查客户、联系人和拜访记录草稿；如果出现多位关键人，会显示“联系人草稿 1”“联系人草稿 2”等多张联系人草稿。
7. 如果出现“客户匹配确认”，先选择使用已有客户，或选择按当前客户草稿新建客户。
8. 点击草稿卡片或“编辑”，在草稿编辑弹窗中对显示“未知，待人为补充”的字段进行人工补充。
9. 可在每张草稿卡片上分别点击“写入客户”“写入联系人”“写入拜访记录”。
10. 也可点击页面底部“全部确认写入”，把客户草稿、多张联系人草稿和拜访记录草稿按依赖顺序写入正式数据库。

注意：

- 当前 MVP 暂不处理录音转写。请先用其他工具把录音转成文字，再粘贴到智能录入。
- Ollama 本地模型需要先在电脑上安装并启动 Ollama 服务。
- 当前开发环境已安装 Ollama `0.30.10`，程序目录为 `D:\DevTools\Ollama`。
- 默认测试模型为 `qwen3:8b`，模型目录为 `D:\FOREXCELTECHClientManager\ollama-models`。
- Ollama 用户身份和缓存目录已迁移到 `D:\FOREXCELTECHClientManager\ollama-home`。
- 如果 Ollama 服务未启动、模型不存在或模型输出不合规，系统会回退到本地规则并给出提示。
- 所有 AI/规则结果只能作为辅助，写入前必须人工核对。
- 录音内容经常无法可靠判断客户是谁，建议先人工预关联客户或联系人。
- 切换预关联客户或联系人后，草稿会按原始抽取结果重新套用关联关系，避免误选后残留错误对象。
- 如果预关联已有客户，客户草稿只作为关联和复核，不会重复新建客户。
- 如果未预关联客户但系统发现疑似已有客户，必须先在“客户匹配确认”中做选择；系统不会静默把客户草稿合并到候选客户。
- 如果模型把正式客户名截短，建议先在客户草稿中修正名称，再选择“按草稿新建客户”。
- 如果预关联已有联系人，第一张联系人草稿只作为关联和复核，不会重复新建联系人；拜访记录会优先关联该联系人，同时继续关联本次新增或确认的其他联系人。
- 更换预关联客户时，如果已选择的联系人不属于该客户，系统会自动清空联系人选择。
- 写入智能录入生成的拜访记录前，系统会检查同一客户、同一联系人、时间接近、主题相似的既有拜访记录。
- 如果发现疑似重复拜访记录，系统会显示合并确认弹窗，并提供“合并到已有记录”和“仍创建新拜访记录”两个明确选项。
- 合并确认弹窗会展示已有记录和当前草稿的字段差异。
- 选择合并时，系统默认保留已有记录的主题、发生时间、地点、客户态度、下一步动作和记录人，只追加摘要/详细内容，并合并参与联系人。
- 必填字段仍为“未知，待人为补充”时，不能确认写入。
- 联系人写入前必须先有客户；如果未匹配已有客户，请先写入客户草稿。
- 拜访记录写入前必须先有客户；如果联系人已写入，会自动作为拜访参与人关联。
- 草稿快照保存在 `D:\FOREXCELTECHClientManager\ai-drafts`。

- 启用 Ollama 本地模型后，文字稿会发送到本机 Ollama 服务，不会发送到外部 AI 服务。
- 选择“仅本地规则”时不会调用模型，但文字稿抽取准确率有限。

## 15. 数据恢复

数据恢复用于把当前数据库整体替换为某个备份数据库。

操作路径：

1. 先确认当前数据是否需要保留；系统会在恢复前自动备份当前数据库。
2. 点击顶部工具栏右侧齿轮按钮，或点击顶部原生菜单“设置 > 打开设置”。
3. 在“数据管理”区域点击“从备份恢复”。
4. 在文件选择窗口中选择 `.db`、`.sqlite` 或 `.sqlite3` 备份文件。
5. 阅读二次确认提示，确认后开始恢复。
6. 恢复完成后，客户、联系人、拜访记录、工作台、日历和客户地图会刷新为备份文件中的数据。

说明：

- 第一版只支持整库恢复，不支持把两个数据库合并。
- 恢复前会自动把当前数据库备份到：

```text
D:\FOREXCELTECHClientManager\backups
```

- 不能选择当前正在使用的 `data.db` 作为恢复来源。
- 如果选择的文件不是有效数据库，或缺少必要数据表，系统会拒绝恢复并提示原因。
- 恢复会替换当前数据，操作前建议确认备份文件来源和时间。

## 17. 客户档案导出

客户档案导出用于把一批客户整理成可阅读、可归档或可二次编辑的文件。

操作路径：

1. 进入“客户”页面。
2. 点击客户页右上方“导出客户”。
3. 在弹框中按客户名称关键词、客户状态、行业、区域筛选导出范围。
4. 选择导出格式：Markdown、PDF、Word，可多选。
5. 选择是否包含关键联系人、拜访/沟通记录。
6. 点击保存后选择导出目录；默认建议使用：

```text
D:\FOREXCELTECHClientManager\exports
```

导出内容：

- 客户基础信息。
- 主要产品信息。
- 客户背景。
- 备注。
- 可选：关键联系人。
- 可选：拜访/沟通记录。

格式说明：

- Markdown：适合轻量归档、知识库沉淀和后续复制整理。
- PDF：适合正式查看、归档和外发。
- Word：适合二次编辑、整理汇报材料。

文件命名示例：

```text
客户档案批量导出-20260704.md
客户档案批量导出-20260704.pdf
客户档案批量导出-20260704.docx
```

注意：

- 当前第一版以筛选后的客户列表为单位生成一组批量档案文件。
- 导出不会修改客户正式数据。
- 如果客户没有联系人或拜访记录，对应章节会显示“未记录”。

## 18. 删除规则

当前客户、联系人、拜访记录删除均为软删除。

表现：

- 删除后默认不再显示在界面中。
- 数据仍保留在 SQLite 数据库中。
- 删除前会弹出二次确认。

注意：

- 当前界面暂未提供“恢复已删除数据”的功能。
- 如误删，应先停止继续操作，并从 `backups` 中找最近备份恢复。

## 21. 工作台日历

工作台中已经加入月视图拜访日历。

日历状态：

- 有正式拜访记录的日期会显示为“已访”。
- 有计划拜访但尚未完成的日期会显示为“计划”。
- 同一天既有正式拜访记录又有未完成计划时，日期颜色优先显示为“计划”，详情弹框中分开展示已拜访记录和计划拜访。
- 日期右上角数字表示当天涉及的客户数量，超过设置上限时显示为 `99+` 或对应上限。
- 日期下方显示农历日期；遇到常见公历节日或农历节日时，优先显示节日名称。

可用操作：

- 日历不再重复显示今日日期大标题，避免和年月选择控件重复。
- 点击日历右上角低调的回到今天图标按钮，可返回今日所在月份。
- 点击年份按钮可打开固定大小的小型年份选择框；一次显示 4 个年份，范围为 1949-2099，鼠标滚轮在弹窗内切换可见年份，右侧显示滚动指示条。
- 点击月份按钮可打开固定大小的小型月份选择框；一次显示 4 个月份，鼠标滚轮在 1-12 月中循环切换，右侧显示滚动指示条。
- 鼠标停留在日历区域时，上下滚动滚轮可切换上一个月或下一个月。
- 点击具体日期打开详情弹框。
- 在日期详情中查看当天已拜访记录。
- 在日期详情中新增、编辑、取消计划拜访。
- 点击“完成”计划拜访时，会打开正式拜访记录表单；保存后计划会被标记为完成并关联到该拜访记录。

日历设置：

- 通过顶部原生菜单“设置 > 打开设置”进入设置页，可以配置已拜访颜色和计划未完成颜色。
- 可以配置日期角标最大值，范围 1-99。
- 设置保存到：

```text
D:\FOREXCELTECHClientManager\config.json
```

注意：

- 日历上的“已拜访”来自正式拜访记录，不来自计划。
- 计划拜访必须选择客户，联系人可选。
- 过去日期不能新增或保存计划拜访；如果需要补历史沟通，请新增正式拜访记录。
- 取消计划拜访不会删除正式拜访记录。
- 农历/节假日为本地内置规则，当前覆盖常见中国公历节日和主要农历节日。

## 22. 客户地图

客户地图页用于从区域角度查看客户分布。

当前能力：

- 左侧导航进入“客户地图”。
- 首页标题为“客户分布”，使用本地 ECharts + GeoJSON 展示中国行政边界地图，按省份展示客户数量。
- 全国缩略图使用本地 `world-atlas` 周边国家真实轮廓作为离线底图，提升地图整体识别度；周边国家仅作背景展示，不参与点击。
- 全国地图初始视图固定为较大的东亚业务视野，顶部周边底图已收窄，不能再缩小到全局小比例；周边国家标签保留但弱化显示。
- 京津冀、上海、粤港澳等拥挤区域的省级标签做了位置偏移，提升可读性；地图仍支持继续放大查看。
- 地图拖拽和缩放范围已受控，避免把地图主体拖出可视区。
- 右下角南海小框已删除，减少空白装饰对客户分布图的干扰。
- 支持按客户状态、行业筛选地图数据。
- 点击省份进入省份视图。
- 省份视图使用本地 GeoJSON 展示省级行政边界，并叠加城市级客户点位。
- 点击城市点位，会在地图内弹出该城市客户名单；该浮动窗口可拖动，但不能拖出地图画布。
- 点击城市客户名单中的客户，可打开客户详情弹框。
- 右上角“待补充”数量支持鼠标悬停查看缺少定位信息的客户名称。
- 进入省份视图后，可点击地图右上角灰色回转箭头图标回到全国视图；图标尺寸已压缩，和右侧统计信息保持同一视觉高度。
- 客户新增/编辑表单已支持省份、城市字段；区县不在界面单独展示，可填写在详细地址中。
- 客户新增/编辑表单支持地址识别：先填写地址并点击“识别地址”，系统会自动补充省份、城市，并按省份自动生成区域。
- 区域为系统自动计算字段，不支持手动填写，避免把城市误填成区域。
- 省份使用受控小弹窗选择器；城市必须先选择省份后才能选择，并且只显示对应省份城市。
- 客户缺少省份或城市时，会进入“待补充”悬浮名单，不会导致地图异常。

说明：

- 当前第一版离线运行，不接入在线地图 API，不上传客户地址。
- 第一版定位精度为省份 + 城市，不精确到街道。
- 详细街道、园区、门牌等信息统一填写在“地址”字段中。
- 现有旧客户如果没有填写省市，系统会尝试从“区域”和“地址”中保守识别；无法识别时需要人工补充省份和城市。
- 当前地图使用随软件打包的本地 GeoJSON、`world-atlas` 派生周边底图和 ECharts 文件，不依赖在线地图服务。
