# UI 统一优化审计

日期：2026-07-03

## 目标

把当前软件从“功能已经可用”推进到“沉稳、统一、适合销售日常高频使用”的商务工具界面。

设计方向：

- 主色：海军蓝侧栏 + 科技蓝主操作。
- 风格：现代线性图标、轻边框、轻阴影、紧凑但不拥挤。
- 信息层级：标题、关键值、辅助信息、操作按钮必须有稳定规则。
- 交互一致：列表、详情弹框、编辑表单、下拉弹窗、浮动窗口使用同一套组件语言。

## 当前主要问题

1. 左侧导航缺少图标系统。
   - 当前导航主要依赖文字和选中背景。
   - 顶部设置、日历回到今天、地图返回使用不同字符符号，和线性图标风格不统一。

2. 联系人页和拜访记录页风格不统一。
   - 联系人页：一行展示大量文本字段，阅读负担高，像数据日志。
   - 拜访记录页：时间线明确，但摘要卡片和联系人页不是同一套视觉模板。
   - 两者都应统一为“列表项摘要 + 关键标签 + 右侧低调进入详情”的模式。

3. 客户页、联系人页、拜访记录页的列表密度不一致。
   - 客户页为卡片网格。
   - 联系人页为纯列表。
   - 拜访记录页为时间线列表。
   - 建议保留各自业务重点，但统一边距、标题字号、标签样式、hover、详情入口。

4. 弹框结构已接近统一，但按钮和头尾还需规范。
   - 客户详情、联系人详情、拜访详情均使用详情弹框，方向正确。
   - 但顶部标题区、右上角关闭按钮、底部操作按钮、危险操作位置需要标准化。

5. 新增/编辑表单控件需要统一精修。
   - 当前输入框、选择框、地址识别按钮已经可用。
   - 下拉焦点橙色、滚动条、字段排列、底部固定按钮需要和品牌色统一。

6. 设置页像“表单堆叠”，不像设置中心。
   - 建议分组为：智能录入、本地存储、日历颜色、系统信息。
   - 路径类字段使用只读信息行，颜色配置使用色块 + 文本值。

7. 顶部按钮可进一步统一。
   - 备份、导出、设置、新增客户现在功能清楚。
   - 建议统一为：次按钮、图标按钮、主按钮三类，不混用字符图标。

## 统一组件建议

### 1. 导航项

结构：

- 线性图标 20px。
- 文本 15-16px。
- 选中项：浅蓝背景 + 左侧 3px 科技蓝竖线 + 图标/文字加亮。
- 未选中项：低饱和浅蓝灰。

建议图标：

- 工作台：grid / layout-dashboard
- 客户：building-2
- 联系人：user-round
- 拜访记录：clipboard-list
- 智能录入：sparkles
- 客户地图：map
- 设置：settings

### 2. 列表项

统一结构：

- 第一行：主标题 + 右侧轻箭头或低调“详情”入口。
- 第二行：所属客户 / 行业 / 区域 / 时间等辅助信息。
- 第三行：标签组或摘要，不超过 2 行。
- hover：浅蓝背景或边框高亮，不使用大面积实色。

差异化保留：

- 联系人：突出姓名、职位/部门、影响力、下一话题。
- 拜访记录：突出时间，时间作为第一视觉锚点。
- 客户：突出客户名称、行业、区域、最近沟通。

### 3. 详情弹框

统一结构：

- 弹框宽度：默认 860-920px，最大 75vw。
- 标题区：标题 + 关键副标题 + 状态标签。
- 内容区：字段卡片 3-4 列；长文本独占一行。
- 底部按钮：左侧关闭，右侧业务操作。
- 危险操作：始终为描边红色，不用大面积红底。

### 4. 表单弹框

统一结构：

- 字段分组：基础信息、地址与区域、业务信息、备注。
- 主按钮固定右下，取消按钮在左侧或主按钮左侧。
- 下拉、日期、年份、月份、地址识别弹窗使用同一阴影、圆角、滚动条。
- 输入聚焦色统一科技蓝，不再出现橙色焦点边框。

### 5. 按钮

按钮类型：

- Primary：主操作，例如新增客户、保存、生成草稿、确认写入。
- Secondary：备份、导出、填入示例、测试连接。
- Ghost/Text：查看全部、查看详情、关闭。
- Danger：删除、清空，默认描边或文字，hover 才强调。
- Icon：设置、回到今天、返回、关闭，统一线性 SVG。

### 6. 下拉和浮层

统一规则：

- 小弹窗固定宽度，不铺满页面。
- 右侧使用细滚动条或滚动指示条。
- 最大高度受控。
- 列表项 hover 使用浅蓝，不使用系统橙色。

## 分页面优化建议

### 工作台

当前状态：

- 三张指标卡和日历逻辑清楚。
- 最近客户标题略重，列表区域可读性一般。

建议：

- 指标图标改为线性图标，不再用“客/联/访”文字块。
- 日历和最近客户卡片标题高度统一。
- 最近客户列表项压缩为：名称、行业/地区、更新时间，减少换行。

### 客户页

当前状态：

- 卡片网格较适合客户概览。
- 详情弹框方向正确。

建议：

- 客户卡片统一高度，长名称最多 2 行。
- “查看详情”改为低调文字按钮或整卡可点击。
- 卡片标签使用统一 chip 样式。
- 详情弹框顶部操作按钮统一顺序：编辑、新增联系人、新增拜访、删除。

### 联系人页

当前状态：

- 信息过于完整地铺在列表里，显得繁琐。
- 与拜访记录页视觉差异明显。

建议：

- 改为“联系人摘要列表”。
- 每项只展示：姓名、客户、职位/部门、影响力、下一话题。
- 关系、偏好、详细背景放入详情弹框。
- 右侧箭头保留但弱化。

### 拜访记录页

当前状态：

- 时间线逻辑正确。
- 信息略单薄，但摘要框又占空间。

建议：

- 时间保留为第一视觉锚点。
- 每条记录统一成时间线卡片：时间、主题、客户、沟通方式、参与人、摘要、下一步。
- 长摘要最多 2 行，详情弹框展示全文。

### 智能录入页

当前状态：

- 左右结构合理。
- 空态时右侧大白板仍偏空。

建议：

- 左侧输入区增加轻量步骤提示：预关联、粘贴文字、生成草稿。
- 右侧草稿区按客户、联系人、拜访记录三类使用一致折叠卡片。
- “全部确认写入”保持右下固定，但禁用态更明显。

### 客户地图页

当前状态：

- 地图完成度较高。
- 筛选、标题、地图卡片已接近统一风格。

建议：

- 筛选条和客户页筛选条统一高度。
- 地图 hover 提示框和客户浮窗使用统一弹层阴影。
- 地图色阶保持低饱和，避免深蓝区域过抢眼。

### 设置页

当前状态：

- 第五阶段已完成重构，页面改为“智能录入 / 工作台日历 / 数据位置”三组商务设置卡片。
- 日历颜色已从普通颜色输入升级为三套马卡龙方案卡片，并保留手动微调和实时预览。

建议：

- 后续可增加“打开目录”快捷按钮。
- 后续可把配置导入/恢复放到数据位置卡片中。
